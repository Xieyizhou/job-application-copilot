# Security policy

## Supported version

Security fixes are provided for the latest published v1.x release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather than a
public issue. Do not include real resumes, API keys, access tokens, private job records, or
generated application materials in reports.

Include the affected version, macOS and Python versions, a minimal reproduction using
fictional data, and the expected versus observed behavior. If private reporting is not
available, open a public issue containing no sensitive details and ask the maintainer for a
private contact channel.

## Scope

Job Copilot is a local application. Reports involving unintended disclosure of Personal
workspace data, browser-companion authentication bypass, unsafe file paths, or generated
bundle contents are especially useful. Third-party job boards and search providers are
outside this project's control and should be reported to their operators when appropriate.
